# Alazab Browser — Skills & Plugins

## الهدف

تخصيص Floorp ليصبح **متصفح عمل داخلي للعزب** مع دمج ChatGPT كأداة أساسية للعمل والتطوير.

---

## Skills

### Alazab Browser

المهارة الرئيسية مسؤولة عن:

- تخصيص واجهة Floorp
- تطبيق هوية العزب
- إعداد New Tab مخصص
- إعداد Sidebar
- إعداد Workspaces
- دعم RTL والعربية
- دمج ChatGPT
- ربط أنظمة العزب
- الحفاظ على توافق Floorp وFirefox

### قواعد العمل

- افحص الكود الحالي قبل التعديل
- لا تعيد بناء Feature موجود
- استخدم أقل تعديل ممكن
- لا تعدل Firefox Core إلا عند الضرورة
- لا تضف Secrets داخل الكود
- حافظ على توافق Upstream
